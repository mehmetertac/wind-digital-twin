# Evaluation

Thresholds and conformal quantiles are calibrated on turbines that do not appear in the test fold. A cutoff estimated on the same machine that is later scored can absorb that machine's residual scale, sensor bias, and the particular normal spell sitting next to the event, so a quiet false-alarm rate on the test turbine is partly a fitted property of that turbine rather than a rule that would have been available for a machine the procedure had not been tuned on. The 2026 Wind Energy Science CARE v6 benchmark (wes-2026-145) separates these roles: a normal-behaviour model may be fit on the status-normal training block supplied with a case (CARE status identifiers {0, 2} only; prediction rows never enter the fit), but the alert threshold is not chosen from that test turbine, and the locked Farm A identities {13, 21} are not used to pick the rule. The same identity split is used for gearbox remaining-useful-life intervals: leave-one-failure-out fits the quantile models and the MAPIE CQR adjustment on the other turbines, so the held-out machine does not set its own prediction interval.

Rise scores use that split per channel. Calibration z-scores from the other assets become an upper-tail conformal p-value, channels are combined by a Bonferroni min-p at the same α = 0.01, and the stored series is `−log10(p)` so the alarm is `p < α / n_channels`. The autoencoder fusion uses the same rule, with the dense autoencoder as one more channel. `status_type_id` is a label marker in the CARE files and is not a model input. A 200-draw bootstrap of the 22 events (seed 0) supplies the 90% intervals in the README.
